The Transformer, Number by Number  ·  Part 8

What a Row Is Not Allowed to See

By Hao Ma  ·  haoma7.github.io

Run 1 receives <start>. Run 2 receives <start> J’aime. How does adding J’aime affect the self-attention calculation?

We continue with I love LLMs and the translation J’aime les grands modèles. Each displayed word counts as one token in this teaching example. The token choices illustrate the inference loop; they are not predictions calculated from our hand-picked parameters.

What does “read” mean? When one position reads another, the other position’s Value vector can contribute to the reading position’s attention output.

Part 7 calculated the first decoder block on run 1. We now repeat its self-attention calculation with the two-token input on run 2. The causal mask controls which positions each Query may read. Later, we use a padding mask to exclude the extra positions added to shorter sentences.

We use the attention calculation from Part 1, Add & Norm from Part 5, and the distinction between a decoder run and a decoder block from Part 7, Section 7.6.

Words, positions and vectors. A token occupies a position in a sequence. A matrix row holds the vector for that position. Its four entries are vector components, not four tokens.
Numerical conventions inherited from Part 7
  • One attention head; each vector has shape 1 × 4, so \(d_{\text{model}}=d_k=4\).
  • Embedding scaling and positional encoding. The original Transformer multiplies each token embedding by \(\sqrt{d_{\text{model}}}\) before adding positional encoding. We omit both operations and use the supplied embeddings directly. This input scaling is separate from dividing attention scores by \(\sqrt{d_k}\), which we still do.
  • Attention output projection \(\mathbf W^O\). After forming the weighted Value sum \(\mathbf Z=\mathbf A\mathbf V\), attention multiplies it by \(\mathbf W^O\) before the residual addition. As in Part 7, Section 7.2.3, we set \(\mathbf W^O=\mathbf I_4\), the \(4\times4\) identity matrix, so \(\mathbf Z\mathbf W^O=\mathbf Z\). We use this setting in each attention sublayer and set all projection biases to zero.
  • LayerNorm uses \(\varepsilon=10^{-5}\), scale vector \(\boldsymbol\gamma=(1,1,1,1)\), and offset vector \(\boldsymbol\beta=(0,0,0,0)\).
  • Rounding for this hand calculation. As in Part 7, use the displayed rounded results in the next step, including the rounded exponentials and attention weights. Round to two decimals; a value exactly halfway rounds away from zero, so 0.385 becomes 0.39, as in Part 7, Section 7.4.3. Within LayerNorm, round only the output vector. This differs from Part 6, which keeps full precision within each calculation. Keeping full precision here can therefore give slightly different final entries.

8.1Two positions, four scores, one forbidden connection

Run 1 starts with the special token <start>. After J’aime is selected, run 2 receives the prefix <start> J’aime. Figure 1 separates the input positions from the new token selected after a run finishes.

We number positions from 1 so that position \(i\) corresponds to row \(i\) of the score matrix and the mask. In zero-based notation, the same position would have index \(i-1\).

In run 2, the decoder input is <start> J’aime. We use the <start> embedding from Part 7, \((1,0,0,0)\), and choose \((1,1,0,1)\) for J’aime. Stacking these embeddings as two rows gives the input to the first decoder block:

\[ \mathbf X_{\text{dec}}=\begin{pmatrix}1&0&0&0\\1&1&0&1\end{pmatrix}. \]

The first row represents <start>; the second represents J’aime. The input has shape 2 × 4. To calculate self-attention, we turn these embeddings into Query, Key and Value vectors. Apply the three projection matrices supplied in Part 7, Section 7.3:

\[ \begin{aligned} \mathbf Q_{\text{dec-self}}&=\mathbf X_{\text{dec}}\mathbf W^Q_{\text{dec-self}}=\begin{pmatrix}-1&0&-1&1\\-1&-1&-3&1\end{pmatrix},\\ \mathbf K_{\text{dec-self}}&=\mathbf X_{\text{dec}}\mathbf W^K_{\text{dec-self}}=\begin{pmatrix}1&0&0&-1\\-1&0&-1&-1\end{pmatrix},\\ \mathbf V_{\text{dec-self}}&=\mathbf X_{\text{dec}}\mathbf W^V_{\text{dec-self}}=\begin{pmatrix}1&0&-1&1\\1&0&0&2\end{pmatrix}. \end{aligned} \]

The first row of each of \(\mathbf Q_{\text{dec-self}}\), \(\mathbf K_{\text{dec-self}}\) and \(\mathbf V_{\text{dec-self}}\) matches Part 7’s calculation for <start>. To check the J’aime Query, multiply \((1,1,0,1)\) by \(\mathbf W^Q_{\text{dec-self}}\). The three 1s select rows 1, 2 and 4 of that projection matrix:

\[ \underbrace{(-1,0,-1,1)}_{\text{row 1}}+ \underbrace{(0,0,-1,-1)}_{\text{row 2}}+ \underbrace{(0,-1,-1,1)}_{\text{row 4}} =(-1,-1,-3,1). \]

The sum is the second row of \(\mathbf Q_{\text{dec-self}}\), corresponding to J’aime.

Each Query is compared with each Key. Divide the dot products by \(\sqrt{d_k}=2\):

\[ \mathbf S_{\text{dec-self}}=\frac{\mathbf Q_{\text{dec-self}}\mathbf K_{\text{dec-self}}^\top}{2} =\frac12\begin{pmatrix}-2&1\\-2&3\end{pmatrix} =\begin{pmatrix}-1&0.5\\-1&1.5\end{pmatrix}. \]

We call this scaled score matrix \(\mathbf S_{\text{dec-self}}\). Rows identify query positions; columns identify key positions. Both axes follow the order <start>, J’aime.

Run 2 produces four attention scores: each of the two Queries is compared with both Keys. Figure 2 highlights the score in row 1, column 2, where the <start> Query is compared with the J’aime Key. The causal mask will block this connection. First, we will calculate what happens without the mask.

Check the highlighted score directly: row 1 of \(\mathbf Q_{\text{dec-self}}\) is the <start> Query, and row 2 of \(\mathbf K_{\text{dec-self}}\) is the J’aime Key. Their scaled dot product gives the score in row 1, column 2:

\[ (S_{\text{dec-self}})_{1,2} =\frac{(-1)(-1)+(0)(0)+(-1)(-1)+(1)(-1)}{2}=0.5. \]

8.1.1First, calculate without a mask

For these hand calculations, we round displayed results to two decimals and use them in the next step; within LayerNorm, we round only the output vector.

Without the mask, softmax processes the entire top score row, \((-1,0.5)\):

\[ (e^{-1},e^{0.5})\approx(0.37,1.65),\qquad \frac{(0.37,1.65)}{2.02}\approx(0.18,0.82). \]

The <start> position would give attention weight 0.82 to J’aime. Compare the resulting weighted sum with run 1 in Figure 3.

\[ 0.18(1,0,-1,1)+0.82(1,0,0,2)=(1.00,0.00,-0.18,1.82). \]

Next, compare the <start> state after the first Add & Norm on the two runs. Add its original input, \((1,0,0,0)\), to the self-attention output, then apply LayerNorm. As in Part 7, the result is the first row of \(\mathbf D\):

\[ (2.00,0.00,-0.18,1.82)\xrightarrow{\text{LayerNorm}}(1.09,-0.91,-1.09,0.91). \]

This differs from the run-1 state, \((1.34,-0.45,-1.34,0.45)\), even though the input at position 1 stayed the same. Information from the later position caused the change.

8.2Where the mask enters the calculation

Each target position represents a prefix for predicting the next token, so its state must depend only on the target prefix ending at that position.

On run 1, the <start> state is computed from <start> alone. On run 2, the causal mask keeps that same information boundary: adding J’aime does not let the earlier <start> position use it.

Section 8.4.2 explains why earlier states therefore remain unchanged; Part 9, Section 9.2.1 explains how this same restriction is used during training.

Now apply the causal mask. In this two-position example, it blocks the connection from the <start> Query to the J’aime Key. That pair will receive zero attention weight, while the other three pairs remain available. We make this change by modifying run 2’s scaled scores, \(\mathbf S_{\text{dec-self}}\), before softmax.

A mask records which pairs are allowed. Figure 4 marks those pairs before we assign the mask its numerical values.

Why mask before softmax? For the first row, the unmasked scores \((-1,0.5)\) produce weights of approximately \((0.18,0.82)\). Simply zeroing the forbidden weight afterward would leave only 0.18 for the allowed position:

Calculation for row 1<start> weightJ’aime weightRow total
Ordinary softmax0.180.821.00
Then zero the forbidden weight0.180.000.18
Mask the score before softmax1.000.001.00

Zeroing the weight and then dividing by the remaining total, 0.18, would also give 1.00. Adding the mask before softmax does both steps at once. The next section shows that calculation.

Key takeawayAdd the mask to the scaled scores, then apply softmax. Forbidden positions receive zero weight; the allowed weights in each row sum to 1.

8.3Add the mask, then apply softmax

The <start> row has scores \((-1,0.5)\). We keep \(-1\) and replace the forbidden score \(0.5\) with \(-\infty\). Its exponential is then zero, so softmax gives J’aime zero weight.

8.3.1From four scores to four attention weights

We can make this change by adding \(-\infty\) at entry \((1,2)\) and adding 0 at the other three entries:

\[ \underbrace{\begin{pmatrix}-1&0.5\\-1&1.5\end{pmatrix}}_{\mathbf S_{\text{dec-self}}} +\underbrace{\begin{pmatrix}0&-\infty\\0&0\end{pmatrix}}_{\mathbf M_{\text{causal}}} =\begin{pmatrix}-1&-\infty\\-1&1.5\end{pmatrix}. \]

Only entry \((1,2)\) changes: \(0.5+(-\infty)=-\infty\). The other three entries add 0 and keep their original scores. The matrix \(\mathbf M_{\text{causal}}\) is an additive attention mask: 0 preserves an allowed score; \(-\infty\) excludes a forbidden pair.

Minus infinity. As \(x\) decreases without limit, \(e^x\) approaches zero. The notation \(e^{-\infty}=0\) expresses an exactly excluded position.
Implementation note: negative mask values

Code may use a large negative number such as \(-10^{9}\) instead of \(-\infty\). The finite value must suit the numeric type and score range; it is an approximation to excluding a position.

Apply softmax separately to each row. In each row, the two weights correspond to <start> and J’aime, in that order. For <start>:

\[ (e^{-1},e^{-\infty})\approx(0.37,0),\qquad \frac{(0.37,0)}{0.37}=(1.00,0.00). \]

For J’aime, both positions are allowed:

\[ (e^{-1},e^{1.5})\approx(0.37,4.48),\qquad \frac{(0.37,4.48)}{4.85}\approx(0.08,0.92). \]

Collect the attention weights in \(\mathbf A_{\text{dec-self}}\). These are weights over key positions, not next-token probabilities:

\[ \mathbf A_{\text{dec-self}}\approx\begin{pmatrix}1.00&0.00\\0.08&0.92\end{pmatrix}. \]

Read the result row by row:

  • The <start> row is \( (1.00,0.00) \). Only the <start> Value contributes to its attention output. The zero weight excludes the J’aime Value.
  • The J’aime row is \( (0.08,0.92) \). Both Value vectors contribute to its attention output.

The mask controls which Value vectors can contribute; it does not remove a token or its row.

The causal ruleIn decoder self-attention, the causal mask keeps connections to the current position and earlier positions, and blocks connections to later positions. At query position \(i\), it keeps key positions 1 through \(i\) and gives every position after \(i\) zero attention weight.

This rule applies separately to each query row. In run 2, J’aime is a later position for <start>, even though both tokens are already in the input. The causal mask keeps each state dependent only on that position and earlier positions on the target side.

✗ Common mistake It is tempting to think replacing the forbidden score 0.5 with 0 would do the same job as the mask, but that is wrong. Scores \((-1,0)\) give weights of approximately \((0.27,0.73)\), because \(e^0=1\), so the forbidden position would still receive most of the weight.

As in Part 7, \(\mathbf A\) holds the attention weights and \(\mathbf Z\) holds the attention output. For decoder self-attention:

\[ \mathbf A_{\text{dec-self}}=\operatorname{softmax}\!\left(\mathbf S_{\text{dec-self}}+\mathbf M_{\text{causal}}\right). \] \[ \mathbf Z_{\text{dec-self}}=\mathbf A_{\text{dec-self}}\mathbf V_{\text{dec-self}}. \tag{8-1} \]

8.3.2Follow both rows through Add & Norm

The attention weights multiply the Value vectors. First, the output for <start>:

\[ 1.00(1,0,-1,1)+0.00(1,0,0,2)=(1,0,-1,1). \]

Next, the output for J’aime:

\[ 0.08(1,0,-1,1)+0.92(1,0,0,2)=(1.00,0.00,-0.08,1.92). \]
Recap: from Query–Key scores to the weighted Value sums

The full sequence of operations is:

  1. Compare: compute each Query–Key dot product.
  2. Scale: divide by \(\sqrt{d_k}\).
  3. Mask: preserve allowed scores and replace forbidden ones with \(-\infty\).
  4. Normalise: apply softmax across each row, over key positions.
  5. Combine: multiply each Value by its attention weight, then add the weighted vectors.
Why \(\mathbf W^O\) with one head? The original paper, Section 3.2.2, defines an attention sublayer with \(h\) heads and an output projection. Setting \(h=1\) in that formula leaves \(\mathrm{head}_1\mathbf W^O\). We keep this structure and set \(\mathbf W^O=\mathbf I_4\) for hand calculation. The basic scaled dot-product attention formula in Section 3.2.1 itself ends at \(\mathbf A\mathbf V\).

These two weighted sums form \(\mathbf Z_{\text{dec-self}}\). With \(\mathbf W^O=\mathbf I_4\), the output projection leaves \(\mathbf Z_{\text{dec-self}}\) unchanged. The residual addition adds each position’s original input to its attention output. For J’aime, row 2:

\[ \underbrace{(1,1,0,1)}_{\text{input}} +\underbrace{(1,0,-0.08,1.92)}_{\text{attention output}} =(2,1,-0.08,2.92). \]

The residual sums for both positions are:

\[ \mathbf X_{\text{dec}}+\mathbf Z_{\text{dec-self}} =\begin{pmatrix}2&0&-1&1\\2.00&1.00&-0.08&2.92\end{pmatrix}. \]

Softmax normalised the attention weights over key positions. LayerNorm now normalises the four components within each position’s residual-sum vector.

Apply LayerNorm to each row separately, using the mean and variance of that row’s four components. For the J’aime residual sum \((2,1,-0.08,2.92)\), the mean is 1.46 and the variance is 1.2516. With our scale of 1, offset of 0 and \(\varepsilon=10^{-5}\):

\[ \frac{(2,1,-0.08,2.92)-1.46}{\sqrt{1.2516+10^{-5}}} \approx(0.48,-0.41,-1.38,1.31). \]

The rows of the resulting \(\mathbf D\) remain in the order <start>, J’aime:

\[ \mathbf D\approx\begin{pmatrix}1.34&-0.45&-1.34&0.45\\0.48&-0.41&-1.38&1.31\end{pmatrix}. \]

Figure 5 compares the calculation on run 1 with the two-row calculation on run 2.

For <start>, both the input vector and the self-attention output are unchanged, so Add & Norm produces the same first row of \(\mathbf D\) as in Part 7’s run-1 calculation.

This completes the masked self-attention and its Add & Norm step. The resulting \(\mathbf D\) then enters cross-attention, following the calculation introduced in Part 7, Section 7.4.

Key takeawayThe mask changes the attention weights before the Value vectors are combined. Add & Norm then produces \(\mathbf D\), the decoder state supplied to cross-attention.

8.4Extend the causal mask to any prefix length

Run 3 receives <start> J’aime les. Compared with run 2, the new les position adds a Query, a Key and a Value. Its Query adds a row to the score matrix, and its Key adds a column, so the score matrix and its mask grow from \(2\times2\) to \(3\times3\):

  • New column 3: the earlier Queries must ignore les. Mask entries \((1,3)\) and \((2,3)\) are \(-\infty\).
  • New row 3: the les Query may read positions 1, 2 and 3. All three mask entries in that row are 0.
  • Existing entries: the top-left \(2\times2\) mask stays unchanged.

The same rule applies whenever the prefix grows, regardless of which tokens occupy the positions.

On run 5, the prefix is <start> J’aime les grands modèles. This run selects <end>. The mask depends on the five positions, not on their embedding values.

8.4.1The triangle, run by run

Use Figure 6 to grow the prefix one position at a time. From run 2 onward, the outlined cells mark the new row and column; the previous mask remains in the top-left corner.

In Figure 6, each new row allows the new position to read itself and all earlier positions. The entries on and below the diagonal therefore remain 0. With five positions, the mask is:

\[ \mathbf M_{\text{causal}}=\begin{pmatrix} 0&-\infty&-\infty&-\infty&-\infty\\ 0&0&-\infty&-\infty&-\infty\\ 0&0&0&-\infty&-\infty\\ 0&0&0&0&-\infty\\ 0&0&0&0&0 \end{pmatrix}. \]

Number rows and columns from 1. Row \(i\) identifies the query position; column \(j\) identifies the key position:

\[ (M_{\text{causal}})_{ij}=\begin{cases}0&\text{if }j\leq i,\\-\infty&\text{if }j>i.\end{cases} \]

The diagonal is allowed because a position may read itself. Entries below the diagonal refer to earlier positions. Entries above it refer to later positions and are masked.

Optional: count the blocked connections

For a prefix of \(m\) positions, row 1 forbids \(m-1\) later positions, row 2 forbids \(m-2\), and the last row forbids none. The total is \(0+1+\cdots+(m-1)=m(m-1)/2\). For five positions, that is 10 of 25 pairs.

8.4.2Why earlier positions keep the same states

On run 2, J’aime can read <start> and itself. Run 3 adds les, but J’aime still reads only those same two positions.

We compare the J’aime position in decoder block 1 on run 2 and run 3. “Unchanged” means unchanged between these two runs at the same stage. Its state still changes as it passes through the steps inside a block.

What must stay fixed. The claim assumes the same source sentence, the same model parameters, the same positional encodings for earlier positions, and no dropout. All four hold at inference.

Why doesn’t the extra score column change softmax? For the J’aime Query in block 1, the scores after masking are:

\[ \begin{aligned} \text{Run 2:}&\quad(-1,1.5),\\ \text{Run 3:}&\quad(-1,1.5,-\infty). \end{aligned} \]

The new entry contributes \(e^{-\infty}=0\), so the softmax denominator remains \(e^{-1}+e^{1.5}\). The attention weights are therefore:

\[ \begin{aligned} \text{Run 2:}&\quad(0.08,0.92),\\ \text{Run 3:}&\quad(0.08,0.92,0). \end{aligned} \]

These are rounded weights. The original two Values are unchanged, and the new Value has zero weight, so the self-attention output is unchanged.

We now check why this equality across runs holds throughout the decoder stack. Assume that every decoder block applies the causal mask in its self-attention sublayer.

Take position \(i\), which already existed before the new token was appended. Follow its dependencies through the first block in Figure 7:

  1. The input at position \(i\) is unchanged. Its token and position have not changed.
  2. Self-attention reads the same allowed inputs. Position \(i\) uses its own unchanged Query and the unchanged Keys and Values at positions 1 through \(i\). The appended position contributes zero to softmax, so the existing weights and weighted output are unchanged.
  3. The first Add & Norm produces the same row of \(\mathbf D\). The residual input and self-attention output are unchanged, and LayerNorm acts on this row separately.
  4. Cross-attention uses the same Query and source memory. Its Query is projected from this position’s unchanged row of \(\mathbf D\). Its Keys and Values are projected from the unchanged source memory \(\mathbf C\), so its output is unchanged. The following Add & Norm also receives the same inputs and produces the same row.
  5. Feed-forward and the final Add & Norm preserve equality across runs. These operations act on each position separately. The same input row gives the same output row, completing the block.

This reasoning applies to every existing position in block 1. Block 2 therefore receives unchanged inputs at all those positions, so the argument repeats. Continue through the decoder stack: at each stage, existing positions have the same states on both runs.

So far, we have recomputed the full prefix on each run. Each decoder block can instead reuse the self-attention Keys and Values of earlier positions and compute the new position’s Query, Key and Value. The new position still goes through self-attention, cross-attention, Add & Norm and the feed-forward steps. The stored Keys and Values are called a KV cache; Part 10, Section 10.8 develops it.

Mathematical equality. Different floating-point implementations can produce small numerical differences. The argument establishes that appending a token introduces no new dependency for an earlier position.

8.4.3The same pattern in every head and block

The causal mask depends only on position indices and prefix length, not on token identity. For the same prefix, every head in every decoder self-attention sublayer uses the same causal pattern. Their projection matrices, scores and attention weights can still differ.

Consider run 2 again, with input <start> J’aime. If block 1 has no causal mask, the <start> state can already contain information from J’aime. Block 2 receives that altered state. Masking block 2 cannot undo the earlier mixing, as Figure 8 shows.

To keep the same restriction throughout the decoder stack, apply the causal mask in every head of every decoder self-attention sublayer. Each block then receives earlier-position states that have not incorporated later target positions. This is the condition used in Section 8.4.2 to explain why earlier states stay unchanged as the prefix grows.

Key takeawayThe causal restriction must be enforced in every decoder self-attention block. Masking only a later block does not prevent an earlier block from mixing information from later target positions.

8.5Exclude padding positions

We now turn to encoder self-attention to examine a different problem: processing source sentences of different lengths together.

Consider two source sentences: I love LLMs and I love. The first has three tokens; the second has two. Their embedding matrices have three rows and two rows, respectively.

8.5.1Two sequence lengths in one batch

A batch is a group of examples processed together. To give both input matrices the same shape in a padded batch, append <pad> to the shorter sentence. It becomes I love <pad>, with three positions. The extra position is a padding position; it is not part of the sentence.

Figure 9 shows the two matrices before and after padding. It supplies the embeddings, including \((0,0,0,0)\) for <pad>. This zero embedding is a choice for the demonstration.

The batch has shape 2 × 3 × 4: two examples, three positions per example, four components per vector. Attention still operates separately within each example. The I position in one sentence does not attend to positions in the other sentence.

We want attention to use the sentence tokens and ignore the added <pad> position. In I love <pad>, column 3 of the score matrix represents the padding Key. A key-padding mask blocks that column for every Query. Encoder self-attention needs no causal restriction, so we can examine the padding mask on its own.

8.5.2Why even a zero padding vector needs a mask

We calculate encoder self-attention for the second example: I love <pad>. For I and love, the Query and Key vectors are the ones calculated in Part 1, Section 1.2; we start the calculation from these vectors:

PositionQueryKey
I\((2,1,0,0)\)\((2,0,1,0)\)
love\((1,2,0,1)\)\((0,2,0,1)\)
<pad>\((0,0,0,0)\)\((0,0,0,0)\)

With positional encoding omitted and projection biases set to zero, the zero <pad> input gives zero Query, Key and Value vectors. Divide each Query–Key dot product by \(\sqrt{d_k}=2\). For example, row 1, column 1 compares I with itself:

\[ (S_{\text{enc-self}})_{1,1} =\frac{(2)(2)+(1)(0)+(0)(1)+(0)(0)}{2}=2. \]

Repeating this for all nine pairs gives:

\[ \mathbf S_{\text{enc-self}}=\begin{pmatrix}2&1&0\\1&2.5&0\\0&0&0\end{pmatrix}. \]

Both axes are I, love, <pad>. Without a mask, the I row gives:

\[ (e^2,e^1,e^0)\approx(7.39,2.72,1.00),\qquad \frac{(7.39,2.72,1.00)}{11.11}\approx(0.67,0.24,0.09). \]
Think for a momentThe padding Value is zero. Can the attention output still change when the padding position receives weight 0.09?

Yes. The padding Value contributes a zero vector. But the padding score is 0, so \(e^0=1.00\) still contributes to the softmax denominator. The weights on the real positions become smaller. Without padding, the same I row gives:

\[ \frac{(7.39,2.72)}{10.11}\approx(0.73,0.27). \]

We want the real positions to behave as they would without the extra fillers. Put \(-\infty\) in the padding column, so every Query excludes that Key:

\[ \mathbf M_{\text{pad}}=\begin{pmatrix}0&0&-\infty\\0&0&-\infty\\0&0&-\infty\end{pmatrix}. \]

The zeros in the mask leave scores unchanged; they are not zero attention weights.

\[ \mathbf S_{\text{enc-self}}+\mathbf M_{\text{pad}}= \begin{pmatrix}2&1&-\infty\\1&2.5&-\infty\\0&0&-\infty\end{pmatrix},\qquad \mathbf A_{\text{enc-self}}\approx\begin{pmatrix}0.73&0.27&0.00\\0.18&0.82&0.00\\0.50&0.50&0.00\end{pmatrix}. \]

Figure 10 compares the attention weights. Follow the bold I row and the outlined <pad> column as you switch between the two steps.

The weights on I and love in the first two rows now match those for the two-token sentence without padding.

The <pad> column now has zero attention weight. Why does the <pad> row still contain nonzero weights?

The mask blocks the padding position as a Key; it does not remove the Query at that position. The <pad> Query row is still computed and can read I and love. Its weights are \((0.50,0.50,0)\), so its attention output is:

\[ \mathbf z_{\text{pad}}=0.50\mathbf v_I+0.50\mathbf v_{\text{love}}. \]

With Part 1’s Values, \(\mathbf v_I=(1,1,0,0)\) and \(\mathbf v_{\text{love}}=(2,0,0,1)\), this gives \((1.5,0.5,0,0.5)\). The output at the padding position is not zero, even though the padding column has been masked.

The padding row can therefore become nonzero, so source padding must remain masked wherever this row can be read: in every later encoder block, and in decoder cross-attention, because the source memory \(\mathbf C\) still contains the row. Section 8.6 lists the mask for every attention sublayer, including target padding.

Here we are masking source padding in attention. Part 9, Section 9.3.2 discusses target padding and which decoder prediction positions are excluded from the training loss.

In our batch, I love LLMs has no padding column to block, while I love <pad> needs column 3 blocked. These two examples therefore use different padding masks.

Key takeawayA zero Value does not prevent its score from affecting softmax. Mask padding columns before softmax; this does not automatically zero the outputs at padding Query positions.

Try it: Apply softmax to love’s unmasked scores \((1,2.5,0)\). Compare the approximate weights \((0.17,0.77,0.06)\) with the masked weights \((0.18,0.82,0)\).

8.6Choose the mask for each attention sublayer

We have used a causal mask in decoder self-attention and a padding mask in encoder self-attention. We now bring these together and identify which restrictions each attention sublayer needs.

Figure 11 answers two questions for each attention sublayer:

  • Must a Query be prevented from reading later target positions?
  • Which Key positions are padding?

Encoder self-attention may use all non-padding source positions. The complete source sentence is available before decoding begins, so cross-attention may read all of them as well. Even target position 1 may attend to I, love and LLMs: these are source positions, not future target positions.

In cross-attention, the Queries come from the decoder, but the Keys and Values come from the source memory \(\mathbf C\). Its padding mask therefore blocks source-padding columns. For the projections from \(\mathbf D\) and \(\mathbf C\), see Part 7, Section 7.4.

For decoder inputs padded to the same length, the causal triangle is the same, but the padding columns can differ between examples. Each example combines that shared causal pattern with its own padding mask.

To see both masks in one example, take the five-position prefix from Section 8.4 and append one padding position: <start> J’aime les grands modèles <pad>. Imagine placing this sequence in a batch whose target inputs have six positions. The first five tokens belong to the prefix; <pad> only fills the extra position. Figure 12 shows how to combine the restrictions.

Consider three Query–Key pairs in this input:

  • \((1,2)\): The causal mask blocks the connection from <start> to the later token J’aime.
  • \((1,6)\): position 6 is both later than position 1 and a padding position. Both masks block this pair.
  • \((6,6)\): the causal mask allows a position to read itself, but the padding mask blocks the <pad> Key.

In this right-padded example, the causal mask already blocks the padding column for the five real Query positions. The padding mask additionally blocks the padding Query from reading its own Key, at \((6,6)\). The example shows how the two restrictions combine.

Follow these outlined entries through Figure 12. Their labels give the Query row and Key column.

Figure 12 combines the restrictions: a pair is forbidden if either mask forbids it. With 0 and \(-\infty\) as mask entries, we implement this by addition:

\[ \mathbf M=\mathbf M_{\text{causal}}+\mathbf M_{\text{pad}}. \]

An entry is 0 only when both masks allow it. If either mask contributes \(-\infty\), the combined entry is \(-\infty\).

Add this combined mask to the scaled score matrix, then apply softmax separately to each row.

The <pad> Query row remains: it can read positions 1 through 5, as in Section 8.5.2.

Implementation note: mask shape and representation

We display a mask with the same shape as the score matrix. Software may broadcast a smaller mask, reusing its entries along compatible dimensions. A causal mask can be shared across examples with the same position layout. Padding masks must still reflect the padding positions in each example. An API may also accept a boolean mask instead of additive values. Follow that API’s convention for which boolean value means “allowed.”

Try it: A decoder input has five real positions followed by three padding positions. In its 8 × 8 combined mask, how many Query–Key pairs are blocked?

Check your count

The causal triangle covers \(8\times7/2=28\) entries. The padding mask adds 1 new entry in row 6, 2 in row 7 and 3 in row 8. The union therefore covers \(28+1+2+3=34\) of the 64 entries.

Key takeawayEncoder self-attention and cross-attention exclude source padding. Decoder self-attention excludes later target positions and target padding. Combine the two restrictions before softmax.
